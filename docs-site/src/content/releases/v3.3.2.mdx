## New

- **The indicators of the [23 November review](/indicator-reviews/2026-11-23/).**
  61 added. No code changed.
- **53 hijacked releases of real npm packages are found by name and
  version.** A project that pins one of them, in `package.json`, a lockfile
  or `node_modules`, is reported as infected. The clean releases of the same
  packages are not reported.
- **Two loader variants are confirmed.** Build configs that open the
  payload with `global.i='5-` used to be listed for review only. They now
  exit 2.
- Two more server addresses, two lock file paths, two file hashes and one
  review-only `package.json` script prefix (`node init &&`).

## Changed

- A folder that 3.3.1 called clean, or listed for review, can now come back
  as infected, with exit code 2. That is these indicators being found, not a
  change to what the exit codes mean.

## Breaking changes

None. Exit codes, commands and flags are as in the previous release.
