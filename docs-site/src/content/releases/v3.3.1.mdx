## New

- **`--no-git` reads no git history.** The files on disk are checked as
  before. It is for a fresh checkout of one commit, as in CI, where the files
  on disk are the last commit and a git finding only repeats them. The
  [GitHub action](/github-action/) passes it on every run. Accepted by
  `check` and `clean`, and refused with `--git-all`. Don't use it on a
  computer you are cleaning: git can still hold the payload there.
- **A manual page.** `man polinrider` after installing with Homebrew or the
  `.deb`, and `polinrider.1` in each `.tar.gz` archive. Every command and
  option is also on one page: [Commands and options](/docs/reference/options/).

## Breaking changes

None. Exit codes, commands and flags are as in the previous release.
